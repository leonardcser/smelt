# Bundled plugins

Much of smelt's own behavior, such as `/diff`, compaction, session titles and
input prediction, is implemented as Lua plugins using the same API available to
you. Read them for working examples.

Enable or disable plugins in your [config](../customize/index.md); the lists
below distinguish opt-in modules from those loaded by default.

### Opt-in

Shipped but not autoloaded. Add `require("smelt.plugins.<name>")` to `~/.config/smelt/init.lua` to enable.

| Plugin | Summary |
| --- | --- |
| `smelt.plugins.goal` | Goal lifecycle plugin. |
| `smelt.plugins.inspect` | Optional plugin: `/inspect` opens a local web UI for browsing sessions, their history, and provider request/response audit data. |

| `smelt.plugins.notebook` | Optional notebook editing: edit_notebook with cell previews, staleness preflight, and per-path locking. |

## File finder

[Find a file and open it in your editor](../guide/workflows.md#find-a-file-and-open-it-in-your-editor)
with `/files` or `/files git`.

No global keybindings are installed. To add your own:

```lua
smelt.keymap.set("n", "<leader>ff", function()
  smelt.cmd.run("files all")
end, { desc = "find workspace file" })

smelt.keymap.set("n", "<leader>fg", function()
  smelt.cmd.run("files git")
end, { desc = "find Git-tracked file" })
```
