# smelt 0.7.0

*Released 2026-11-02*

### Breaking

- Secret redaction is removed. Delete `redact_secrets` from your config.
- Colors in Lua use one format. Replace `{ ansi = 244 }` with `244` and `{ rgb = { r, g, b } }` with `{ r, g, b }`, and `ansi_color` with `prefix_color` on completer and picker items.
- All bars share one API, called with a colon: `smelt.statusline:add(name, fn)` replaces `smelt.statusline.add(name, fn)`. `smelt.headerline` works the same, and `smelt.prompt_bar.top` and `smelt.prompt_bar.bottom` are now `smelt.prompt.top` and `smelt.prompt.bottom`.
- `smelt.transcript.get_renderer()` returns a snapshot of the composed renderer. Call `smelt.transcript.render_part` to render with the current composition.
- `smelt.settings.transcript` raises on unknown top-level keys. Only `show_timestamps`, `view` and `limits` are accepted.
- `smelt-term` has a new rendering and layout API. See its README.

### Added

- The [plugin gallery](../gallery/index.md) shows 54 Lua plugins running: themes, transcript skins, bars, screen effects, games and more.
- Plugins can draw over the whole finished screen with `smelt.paint.frame`.

  <figure class="term" data-replay="../../assets/replays/gallery/barrelroll.json" aria-label="/barrelroll spinning the whole screen one full turn" markdown="0"><pre class="term__screen" aria-hidden="true"></pre></figure>

- Customize the statusline, headerline and prompt bars, or create your own with `smelt.bar.new`. Bar sources receive the available width, and `bar:set_view` replaces a bar with a custom layout.

  <figure class="term" data-replay="../../assets/replays/gallery/pills.json" aria-label="A statusline of rounded pills" markdown="0"><pre class="term__screen" aria-hidden="true"></pre></figure>

- Plugins can restyle dialogs (`smelt.dialog.compose`), start from a colorscheme (`smelt.theme.spec`) and render any transcript part (`smelt.transcript.render_part`).

  <figure class="term" data-replay="../../assets/replays/gallery/bubbles.json" aria-label="The transcript as a messenger with chat bubbles" markdown="0"><pre class="term__screen" aria-hidden="true"></pre></figure>

- Styles take any color, including theme groups such as `"Comment"`. `smelt.theme.rgb` resolves one to RGB.
- Window decorations can be see-through (`transparent = true`).
- `smelt.git.index` stages a range of files in a diff section.

### Changed

- The first request no longer waits for the model catalog.
- Usage limits for `codex`, `kimi-code` and `claude-code` share one cache and report reset times as `resetAt`.

### Fixed

- Turns paused by a quota or rate limit resume on their own in `"goal"` mode even without a goal.
- Session saves retry when storage is busy. Moved records, catalog upkeep and a closed owner no longer fail them.
- smelt quits when its terminal goes away instead of running on.
- Dragging a scrollbar keeps the thumb under the pointer.
- The statusline shows the cursor position after each keystroke.
- Usage reset notices stay above the prompt bar after a dialog closes.
- Repeated messages fold into one entry.
- Custom transcript presentation survives rendering and compaction keeps repeated tool details.
- The diff view no longer freezes on very long lines.
- The splash screen shows the theme background around the logo.
- Drag selection shows in diff and resume previews.
- Concurrent upgrades no longer build the same version twice, and upgrades honor the install root.
