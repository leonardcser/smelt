# smelt 0.6.3

*Released 2026-10-28*

### Added

- Run your installed Claude Code as a native agent backend, with background work that keeps running.
- smelt downloads and verifies upgrades in the background.
- Vim text objects look ahead to the next pair or code block, like nvim.
- Bash hints how to background a slow command.

### Changed

- Faster first frame and lower CPU use while waiting on the model.
- Fuzzy pickers use smart-case matching.

### Fixed

- Session titles come from your request, not from smelt or Claude Code context.
- Streamed text types out smoothly between chunks.
- The transcript stays steady while resizing, zooming, or loading blocks.
- Rewind no longer crashes on in-flight output.
- Truncated live previews show the full tool output when done.
- Images reappear after the terminal regains focus.
- Permission checks block shell expansions on heredoc lines.
- `smelt.tick.every` keeps running while idle.
- Claude Code exits show the exit status and error output.
