# smelt 0.6.1

*Released 2026-10-26*

### Added

- `snake` ships as a built-in plugin, and plugins can wrap the main layout.
- Documented `statusline`, `headerline` and `tips` namespaces in the Lua API.
- Goals can be cleared on explicit request.
- Sessions release superseded revision content, so long sessions stop growing with every save.

### Changed

- The default colorscheme picks a syntax theme that fits the terminal background.
- `early.lua` is treated as config: editing it asks for trust, like `init.lua`.
- Process overlay navigation is standardized.
- The metrics ledger stays bounded by rolling old calls into daily totals.

### Fixed

- The Codex provider points at its API base, so requests need no normalization.
- The permission check covers commands around a heredoc that never terminates.
- The shell parser no longer panics on oversized brace and tilde numbers or on heredoc tags with
  carriage returns.
- The working spinner no longer freezes after a turn ends.
- Tool bodies collapse while a permission request is pending.
- Kitty graphics probing is skipped on terminals without kitty graphics.
- Scrolling no longer reuses stale rows, and a wheel step replaces a superseded seek.
- `session doctor` stays fast.
- Lua-to-JSON conversion is bounded and unified.
- Dialogs reject bad options before they open.
