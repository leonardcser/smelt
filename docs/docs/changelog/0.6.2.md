# smelt 0.6.2

*Released 2026-10-27*

### Added

- Vim motions and operators in the prompt, viewers and transcript: registers, marks, jump list
  (`ctrl-o`, `ctrl-i`), `gv`, `gU`/`gu`/`g~`, shift and increment operators, paragraph and block
  motions, `H`/`M`/`L`, `zt`/`zb`, `f`/`t`/`;`/`,` and `%`.
- Search the word under the cursor with `*` and `#`, also in the prompt in vim normal mode.
- `ic` and `ac` select a fenced code block in the transcript, so `yic` and `yac` copy it.
- Composable prompt bars and a working indicator that shows tool heat.
- Copied text flashes in the prompt and in selectable panes. The flash color follows the selection color.
- smelt downgrades RGB colors to the 256-color palette on terminals without truecolor.
- The splash fire ignites when smelt launches.
- The docs show pressed keys under terminal replays, and more workflows on the homepage.

### Changed

- Word, sentence, paragraph, text object and Visual commands, counts, dot-repeat, autoindent and
  linewise registers follow nvim more closely.

### Fixed

- Plugins load from symlinked files.
- The models.dev catalog loads in the background and fails fast offline, so the first request does
  not stall.
- A docked dialog no longer leaves the hidden prompt's viewport behind.
