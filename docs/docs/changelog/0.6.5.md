# smelt 0.6.5

*Released 2026-10-30*

### Added

- `/donut` spins a 3D donut over the screen while you keep working.
- Overlays can be see-through (`transparent = true`): only what they draw covers the screen, and the mouse passes through.
- The Claude Code backend shows background shells when they finish and native context compaction.

### Changed

- The `/btw` dialog opens at half the screen height.
- Streaming answers hold math until it closes, so raw TeX no longer flashes before it renders.

### Fixed

- Prompt pickers and notifications fit beside a sidebar and stay under floating windows such as games.
- `Ctrl-W` leaves a floating window for the pane under it.
- Focusing a transcript that follows new output puts the cursor on its last line.
- Block jumps in the transcript no longer stall, flicker the scroll pill or land under it.
- The Claude Code backend shows thinking text and continues after an empty submit.
- `/btw` shows a failed or empty answer instead of nothing.
- `buf:source` text shows on plain buffers.
