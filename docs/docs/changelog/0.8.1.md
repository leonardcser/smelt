# smelt 0.8.1

*Released 2026-11-18*

### Upgrade notes

- smelt no longer uses the OS keyring for OAuth credentials, so startup no longer prompts for macOS Keychain access. If your credentials were stored only in the keyring, sign in again with `smelt auth`.

### Added

- Preview image attachments and move them within the prompt before sending.
- Stash a Vim visual selection without stashing the rest of the prompt.
- Redeem available Claude Code quota reset credits from `/usage`.
- See messages between Claude Code agents in the transcript.
- The startup banner shows upgrade status next to the version.

### Changed

- Background results waiting to be delivered appear dimmed in the transcript.
- Large pastes stay responsive while you edit them, and quitting and resuming stay fast as sessions grow.
- Terminal animations are smoother.

### Fixed

- Removing a message from the queue no longer causes it to send twice.
- Claude Code background work that hits a quota while waking from idle resumes after the quota resets. Status shows waiting during quota recovery.
- Notes added during a turn no longer appear twice in the transcript.
- On Linux, the file index no longer exhausts inotify watches.
- Rewinding or unstashing no longer loses the current prompt draft.
- A quick repeat of `Ctrl+C` after clearing the prompt no longer quits smelt or cancels the turn.
- Mermaid diagrams no longer inherit the code block background.
- `/resume` hides agent sessions.
