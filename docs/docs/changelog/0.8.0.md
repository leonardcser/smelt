# smelt 0.8.0

*Released 2026-11-08*

### Breaking

- Sessions live in one SQLite database. The first start imports smelt 0.7 data.
- Goals and notebook editing are opt-in. Add `require("smelt.plugins.goal")` or `require("smelt.plugins.notebook")` to `~/.config/smelt/init.lua`.
- `donut` is opt-in. `barrelroll` loads by default.
- The status file schema is 2. It drops `expires_at_ms`, `boot_id` and `process_start_time_ticks`. A held `<pid>.lock` proves a session is alive.

- Sessions report when a workflow completes.

### Changed

- Startup is faster, and idle smelt uses less CPU.
- Streaming, session saves, `Ctrl+R` history search and session search are faster.
- Sessions take less disk space.
- Streaming code is no longer re-highlighted on every update.
- Very large session archives stay fast.
- Jumping between blocks in long sessions is faster.
- `/btw` uses the active model by default.

### Fixed

- Turns paused by a quota limit resume at the provider reset, including limits hit between turns.
- Jumps no longer snap back in long sessions.
- Dialogs stay closable after a workspace switch.
- Rebound keys are kept after a stale removal.
- Permission rule parsing no longer stalls on deeply nested braces.
- A stashed draft returns after completer commands.
- Command pickers open with an empty filter.
- The `bash` tool accepts `timeout_ms` as a string.
- Orphaned temporary session folders are removed.
- Chained dialogs no longer flicker when they swap.
- `/ps` runs during a turn instead of being rejected as busy.
- Keys typed during the startup color probe are kept.
- Saving a scrolled-back transcript no longer truncates it.
- Compaction recovers when the model history is too large.
- Queued messages are removed before `Escape` runs its other actions.
- Input is kept during a terminal handoff to the editor.
- The prompt view stays on the cursor after `gg`.
- The spinner animates smoothly when a turn starts.
- Rewinding to a slash command opens the command picker.
- Unicode updates no longer leave stale cells on screen.
- The sleep inhibitor no longer asks for a password.
- Claude Code: native edits preview in the approval dialog, compaction shows in the transcript, prompts queue while it works, and status shows waiting during background work.
