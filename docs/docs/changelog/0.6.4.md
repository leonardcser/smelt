# smelt 0.6.4

*Released 2026-10-29*

### Added

- Expanded transcript blocks show the full command.
- Linux release binaries are static and run on any distribution.

### Changed

- Faster search in large sessions.
- Syntax highlighting stays fast on any line range, including very large files and diffs.

### Fixed

- HTTPS requests work on systems without a CA bundle.
- Rate-limit reset times display correctly on every platform.
- Streaming edit previews show unread-file errors immediately.
- Block navigation in the transcript aligns targets at the top.
- Repeated searches in the diff preview keep focus and `n` stepping.
- The prompt-bar animation stays in sync with the clock.
- `smelt upgrade` passes the correct Cargo install arguments.
- The Claude Code backend shows the context usage percentage.
- Helper requests use the latest Luna and Haiku models.
- Session inspection retries while the catalog is busy.
