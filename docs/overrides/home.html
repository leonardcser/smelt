A fast, open-source, Lua-scriptable coding agent for the terminal.

curl -fsSL https://smeltagent.dev/install.sh | sh
cargo install --locked --git https://github.com/leonardcser/smelt.git smelt-agent
Linux, macOS and Windows binaries on GitHub releases

MIT · GitHub · Linux, macOS and Windows · beta until 1.0

Move around the conversation

Leave the prompt and move through the conversation with vim keys: jump between messages, search, select a code block and yank it into the prompt. Turn it on with smelt.settings.vim = true.

Plugins

A plugin is one Lua file. Put it in ~/.config/smelt/plugins/ and it loads at once. It can draw on any cell of the screen. You can also ask smelt to write one.

Plugin gallery →Write a plugin →

Use any model

Sign in with ChatGPT, GitHub Copilot, Kimi Code or Claude Code, or use any OpenAI-compatible server. Switch with /model at any time.

Themes

More than thirty themes are included. Write your own in a few lines of Lua.

Math

Equations show as images. Terminals without image support get plain Unicode.

Small and fast

smelt installs as one 46 MiB binary and uses 34 MiB at start. The other four agents write 313 to 1684 MiB and use 110 to 328 MiB. Measured on 2026-11-02 with a smelt main dist build and the latest stable comparison-agent releases, while waiting for the model. Lower is better.
