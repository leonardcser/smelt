Plugins in a few lines of Lua

Drop a file in ~/.config/smelt/plugins/ and it loads, no restart.

Changes sidebar

Every file the agent changed, with line counts, beside the conversation.

Snake

Built in, in plain Lua like yours. Type /snake while the agent works.

Statusline

Mode, directory, branch and changed files, in the style of lualine.

Spinner

Replace the working indicator with anything, like words that glitch in and out.

Themes

Over thirty bundled themes, or build your own and change any color you like.

LaTeX in the terminal

Equations render as typeset images, with a Unicode fallback in any terminal.

Vim mode

Insert, normal and visual modes in the prompt and the transcript, with motions, text objects, yank and undo. One line turns it on: smelt.settings.vim = true
